# Security

If you find a security problem in Riptide, please report it privately through GitHub's **Report a vulnerability** button on the Security tab of this repository instead of opening a public issue. We'll reply as soon as we can.

What we treat as security issues:

- Anything that lets a Blueprint, share code or imported file run commands or inject config on a server
- Ways to leak secrets such as license keys or database passwords
- Problems in the CLI that write files outside the chosen folder
- Cross-site scripting or data leaks in the Studio

Riptide never needs your Rockstar, Cfx.re or Discord passwords. Never paste them into a Blueprint or share code.
