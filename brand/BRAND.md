# Riptide brand

## The idea

A riptide is the current that pulls everything out to sea. Riptide pulls a server's scattered pieces (configs, bots, hosting, rules, economy) into one place. The look is a coastal city after sunset: warm sky, dark water, neon on the shore. It's inspired by Florida nightlife and beach culture, not by any game's art or branding.

## Logo

A sunset cut by a curling wave. The sun is the server, the wave is the current. The curl at the end is the one detail that makes it ours.

| File | Use |
| --- | --- |
| `mark.svg` | The mark on its own, any size from 16 px up |
| `lockup.png` | Mark and wordmark, transparent |
| `logo-animated-dark.svg` / `logo-animated-light.svg` | README and splash: the logo building itself |
| `logo-512.png`, `logo-tile-512.png` | App icons and avatars |
| `banner.png`, `social-preview.png` | GitHub social preview and headers |

Give the mark clear space equal to the height of the curl. Don't recolour the wave, add outlines, or put the mark on a busy photo.

The horizon gradient (Sunset → Coral `#FF6F7D` → Flamingo) is used sparingly: in the logo, the top bar's horizon line, the launch button and the readiness sun.

## Type

- **TeX Gyre Adventor Bold** for display: geometric and wide, with an 80s coastal-signage feel.
- **DM Sans** for everything else.
- **Anonymous Pro** only for real code and file names.

## Motion

Small and purposeful. The startup animation (sun rises, wave draws, letters surface) is the one big moment. Elsewhere, motion answers what the user did: the nav highlight slides, meters fill, the deploy button fills like a tide. Everything respects reduced-motion settings.

## Voice

Plain, warm, a little playful. Talk to server owners like a friend who's run a few servers. Say what a button does ("Deploy to Miami", not "Submit"). Errors say what happened and how to fix it.
