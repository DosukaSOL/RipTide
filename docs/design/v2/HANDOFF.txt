DESIGN PHILOSOPHY
-----------------
Professional in the way a premium large-budget gaming application's companion UI
might feel: confident type, deliberate spacing, calm color, excellent alignment,
quality micro-interactions, and strong art direction. NOT an imitation of an
official Rockstar asset, logo, UI, or trademarked styling. Maintain clear independent
project attribution.

Motion is a REWARD to the user action, not an ambient light show.
- The animated logo on initial launch may be the one showpiece (already in repo).
- Tab changes: 160–240 ms subtle fade + 4–8 px slide.
- Sidebar active indicator: gentle 160–240 ms slide.
- Hover: small contrast/surface change, not bright glow around every card.
- Buttons: 120–160 ms response and a tiny pressed translation.
- Map filters/markers: graceful 150–250 ms state changes.
- Success: brief seafoam confirmation, never constant neon pulsing.
- Respect reduced-motion preferences and OS accessibility settings.
- Cap animation work and avoid repainting heavy surfaces under performance plots.

USABILITY
---------
1. One obvious primary action per major screen. Don't show five competing CTA buttons.
2. Show only controls needed for the current task; advanced options can be disclosed.
3. Make tabs, search, filters and empty states genuinely usable, not cosmetic.
4. Preserve every existing RipTide Studio action, state, validation, deploy pathway
   and keyboard/mouse affordance. No core behavior changes during a design pass.
5. Avoid made-up live FPS, payouts, game-version IDs, map locations, 'healthy systems'
   or completed features without real data to back them up.
6. Keep unreadable microcopy out. Target readable desktop sizes and contrast.
7. Support keyboard navigation and clear focus indicators, not hover-only UI.
8. Avoid needless dialogs; use contextual drawers/inspectors for advanced tasks.
9. Honor 125%, 150%, and 200% Windows display scaling; keep all content available
   at reduced window widths via sensible responsive layouts and scrolling.
10. Avoid resource-intensive constantly running animations when a game is active.

BUILD NOW / FUTURE GATING
-------------------------
A. RipTide Studio:
   Keep all existing server studio functionality and branding. Plug it into the
   RipTide Tools shell. Build a compatibility bridge, not a rewrite of core logic.

B. ViceLab:
   Build a performance telemetry and results infrastructure for supported PC games
   already available. Provide empty states, basic benchmark templates, import/export,
   screenshot comparisons, and hardware profiles. Add real GTA VI PC-specific tests,
   game detection and recommendations ONLY when the PC game can be tested.
   Never fabricate data or claim automatic game optimization without reliable tests.

C. Heist Ops:
   Build mission-agnostic local templates, operation phases, role slots, checklists,
   notes, sharing contracts, persistence, and a safe room-synchronization design.
   Online sync is only 'live' once it has actually been implemented and tested.
   Avoid claiming any GTA VI Online missions, rewards, coordinates or mechanics now.

D. Interactive Map:
   Build pannable/zoomable map viewer, layers, robust category filters, search,
   saved filters, user notes, bookmarks, pop-out support and a versioned content
   import pipeline. With no verified GTA VI full-map data, show a legitimate blank,
   schematic or community-added layer. Clearly distinguish official, verified,
   community, and personal map records; moderation and provenance required.

E. Workspaces:
   Open independent tool windows simultaneously; support detach/re-dock, move to
   second display, restore saved geometry, recover if monitor unplugged, and persist
   tool state. Avoid a single global active-tool state that unmounts other modules.

F. Roadmap:
   List as future modules until researched/tested: patch tracker, vehicle/property
   planner, loadout builder, mission/activity tracker, creator toolkit, clip
   organizer, discovery journal, crew finder, economy planner, route library,
   community benchmark browser and multiplayer debrief timelines.
   Add release gates that depend on GTA VI PC/Online availability and policy review.
