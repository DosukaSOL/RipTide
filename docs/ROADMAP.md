# Roadmap

Riptide is being built ahead of GTA VI on PC. Dates depend on Rockstar, so this roadmap is ordered by phase rather than by month. It will change as we learn more about GTA VI Online.

## Phase 0: Foundations (now)

- Blueprint format and validation
- Integration catalog, compatibility check, performance budget
- Economy forecast with autopilot
- Plain-English rulebook with Discord and web output
- FiveM adapter, docker stack, CLI
- Studio design, brand and startup animation

## Phase 1: Real servers on GTA V

- Riptide runtime resource that applies world, economy and rule settings in game
- Discord bot: role sync, applications, rules post, deploy announcements
- Custom resource import with basic safety scanning
- Public preview of the Studio

## Phase 2: Riptide hosting

- One-click deploys in eight regions
- Preview servers and merges
- Deploy history with rollback
- Live tick time, player counts and economy after launch
- Backups with point-in-time restore

## Phase 3: GTA VI

Starts the moment Rockstar publishes PC server tooling.

- GTA VI adapter for the official server framework
- Riptide Core framework generated from Blueprints
- Catalog entries ported or rebuilt for GTA VI
- One-click migration of existing Blueprints
